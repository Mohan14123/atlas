# Atlas

Distributed Job Scheduling Platform

## Features

- Immediate jobs
- Delayed jobs
- Scheduled jobs
- Recurring jobs
- Batch jobs
- Queue priorities
- Concurrency limits
- Retries
- DLQ
- Worker heartbeats
